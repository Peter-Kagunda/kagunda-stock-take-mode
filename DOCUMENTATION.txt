1. INTRODUCTION
--------------------------------------------------
Stock Take Mode for WooCommerce lets store administrators pause
site-wide or product-specific purchasing during inventory counts,
maintenance periods, or seasonal stock-taking events.

--------------------------------------------------
2. INSTALLATION
--------------------------------------------------
1. Make sure WooCommerce is installed and active.
2. Install the plugin from the WordPress.org plugin directory, or upload
   the plugin ZIP under Plugins > Add New > Upload Plugin.
3. Activate the plugin.
4. Go to WooCommerce > Stock Take Mode to configure it.

--------------------------------------------------
3. CORE FEATURES
--------------------------------------------------
- One-click Start now / Stop now, and a toolbar shortcut to turn it off.
- Optional scheduled start/end window in the store's timezone.
- Product and category exception lists.
- Role-based bypass for store staff, and a "Preview as customer" button.
- Countdown banner with color presets, live preview, position and scope.
- Waitlist capture with spam protection, search, removal and CSV export.
- Automatic (batched) re-opening email to the waitlist.
- Blocking for classic add-to-cart, AJAX add-to-cart, Cart/Checkout blocks
  and the Store API.
- Admin bar status indicator and dashboard widget.
- Settings import/export as JSON, for backups or multi-site setup.

5. DEVELOPER HOOKS
--------------------------------------------------
Filters
  kagstm_is_window_active ( bool )      Override whether the window is open.
  kagstm_message ( string )             Customer-facing message.
  kagstm_show_banner ( bool )           Whether to print the banner.
  kagstm_capability ( string )          Capability needed to manage the plugin.
  kagstm_broadcast_batch_size ( int )   E-mails per batch (default 25).
  kagstm_waitlist_max ( int )           Maximum subscribers (default 5000).
  kagstm_waitlist_rate_limit ( int )    Sign-ups per visitor per 10 minutes (default 8).

Actions
  kagstm_started                        Stock Take Mode began.
  kagstm_ended                          Stock Take Mode ended.
  kagstm_waitlist_subscribed ( $email ) A visitor joined the waitlist.

--------------------------------------------------
6. SECURITY & PRIVACY NOTES
--------------------------------------------------
- The plugin does not send any data to third-party servers and does not
  track site usage. All data (settings, waitlist emails, blocked-attempt
  counter) is stored only in your own WordPress database.
- The settings screen does not accept arbitrary CSS, JavaScript, or PHP;
  banner appearance is controlled through fixed, validated options.
- Every admin action is protected by capability checks and nonces.
- Waitlist emails are exposed to WordPress's personal data export and erase
  tools, and suggested privacy policy text is added under Settings >
  Privacy.
- If you use a page cache or CDN, clear it when you start or stop Stock
  Take Mode.
