# Kagunda Stock Take Mode for WooCommerce

[![WooCommerce Compatibility](https://shields.io)](https://woocommerce.com)
[![WordPress Compatibility](https://shields.io)](https://wordpress.org/)
[![License](https://shields.io)](https://gnu.org)

**Kagunda Stock Take Mode** is a lightweight WooCommerce utility extension allowing store owners to temporarily pause purchasing across the storefront or on specific items during inventory counts and warehouse audits.

## 🔍 Why Use Stock Take Mode?

Live customer orders during a physical inventory count can cause discrepancies between digital records and physical stock. This plugin introduces a customizable "Stock Take Mode" to freeze purchasing operations safely without losing storefront presence or SEO visibility.

---

## 🚀 Key Features

* **Restriction & Scheduling:** Toggle store-wide purchasing restrictions or schedule automation windows.
* **Exceptions & Bypass:** Set product/category exceptions and allow administrator or shop manager role bypass.
* **Engagement & Waitlist:** Features a sticky countdown banner, waitlist lead capture with email broadcasts, an admin bar indicator, and a dashboard metric widget.
* **Management:** Includes settings import/export via JSON and WooCommerce log integration.

---

## 🛠️ Installation & Configuration

### Installation Methods
1. **WordPress Plugin Directory (Recommended):** Navigate to **Plugins > Add New**, search for `Kagunda Stock Take Mode for WooCommerce`, install, and activate.
2. **Manual ZIP Upload:** Upload the plugin ZIP archive via **Plugins > Add New > Upload Plugin** in your WordPress admin panel and activate.

### Configuration
Access **WooCommerce > Stock Take Mode** after activation to manage Rules, Design & Engagement, Waitlist management, and Import/Export settings.
